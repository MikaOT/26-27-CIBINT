# Entregas en grupo

Esta carpeta reúne las entregas de las actividades que se realizan en grupo. Hay una carpeta por actividad y, dentro de cada una, una carpeta por grupo.

| Actividad | Carpeta | Grupos |
|---|---|---|
| `A02` · [Plan de investigación](../../actividades/A02-plan-de-investigacion/README.md) | [A02/](A02/README.md) | [grupo1](A02/grupo1/README.md) · [grupo2](A02/grupo2/README.md) |

## Reglas comunes

| Regla | Detalle |
|---|---|
| Creación de las carpetas | Se crearán previamente, con los archivos de partida que indique el enunciado |
| Quién entrega | Solo el portavoz del grupo, con un único *pull request* desde su *fork* |
| Dónde se trabaja | Solo dentro de la carpeta del propio grupo |
| Con quién se trabaja | Únicamente con el propio equipo, sin compartir trabajo con otros grupos antes de la entrega |
| Revisión del resto del grupo | Cada miembro que no entrega comenta en el *pull request* que ha revisado la entrega y que está conforme |
| Archivos fuera de la carpeta del grupo | **Si el *pull request* modifica, añade o elimina cualquier archivo fuera de la carpeta del grupo, la actividad no se evalúa para el grupo** |

Las normas generales de entrega están en [entregas/README.md](../README.md). El enunciado de cada actividad prevalece sobre estas reglas.
